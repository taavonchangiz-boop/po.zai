# پٌست‌یار (Postyar)

این repository شامل منابع مرجع و قرارداد اجرایی ساخت نسخهٔ جدید پٌست‌یار است.

## Reference
- `Asovin/` — منبع مرجع قابلیت، UX و assetهای بصری تأییدشده.
- `postyar/` — منبع مرجع قابلیت‌های پیشرفته و الگوهای داده/معماری.

## AI Execution Contract
قرارداد ساخت پروژه در `AI-SPEC/` قرار دارد.

برای شروع یک AI coding agent، فایل زیر را بخوانید:

`AI-SPEC/BOOTSTRAP-PROMPT.md`

سپس agent باید طبق `AI-SPEC/MASTER-PROMPT.md` و سایر اسناد همان پوشه فقط Phase 0 را انجام دهد و تا Gate بعدی متوقف شود.

## Target Runtime
Node.js 22.23.2 / cPanel / Terminal بدون SSH
